# Gratissimo

Jobportal for frivillige og foreninger. 
Svendeprøve 
September 2026.

Design og API fra Kasper (TechCollege).

## Techstack
- React 19 + TypeScript
- Vite
- React Router
- SCSS Modules
- react-icons
- js-cookie

## Kør lokalt

Backend:

cd Backend
cp .env.example .env
npm install
npm run dev

Kører på localhost:4000.

Frontend:

cd Frontend
npm install
npm run dev
